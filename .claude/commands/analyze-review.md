Pull Requestに寄せられたCopilotのレビューコメントを取得し、各指摘が妥当かどうかを判断してください。

## 対象PR
$ARGUMENTS にPR番号が指定されている場合はそのPRを対象にする。
指定がなければ `gh pr list` で直近のオープンPRを対象にする。

## 手順
1. `gh api repos/{owner}/{repo}/pulls/{number}/comments` でレビューコメントを取得する（`{owner}/{repo}` は `gh repo view` で確認する）
2. 各コメントについて、指摘対象のファイルを読み、指摘内容が妥当かどうかを判断する
3. 判断結果を以下の形式で報告する

## 報告形式
各コメントについて：
- **ファイル・行番号**: 指摘箇所
- **指摘内容**: Copilotの指摘の要約
- **判断**: 妥当 / 一部妥当 / 不当
- **理由**: 判断の根拠
- **対応案**: 修正する場合は具体的な修正内容、しない場合は返信案

## 注意
- この段階ではコードの修正や返信は行わない。分析と報告のみ行う。
- ユーザーが対応方針を確認・指示してから、次のステップに進む。
